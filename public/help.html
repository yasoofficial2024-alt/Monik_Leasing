Help & Support

Welcome to the MONIK GROUP Hire Purchase Quotation System. This section provides basic guidance for using the application.

Using the System

  • Select the vehicle Brand and Model.
  • Enter or verify the Selling Price.
  • Enter the applicable Discount and Down Payment.
  • Verify Document Charges and RMV Charges.
  • Verify the Interest Rate and Facility Period.
  • Click Calculate to generate the quotation.
  • Use Amortization Schedule to view the payment schedule.
  • Review all calculated amounts before providing the quotation.

If a Calculation Looks Incorrect

  1. Check the Selling Price.
  2. Check the Discount and Down Payment.
  3. Verify the Interest Rate.
  4. Verify the Facility Period.
  5. Click Calculate again.
  6. If the problem continues, contact the system administrator.

System / Access Issues

  • Reload the application if it is not responding.
  • Contact the administrator if access is restricted.
  • Do not share your login credentials.
  • Report incorrect financial or vehicle information.
